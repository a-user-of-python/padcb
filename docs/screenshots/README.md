# Screenshots

Drop screenshot PNGs in this folder, then uncomment the image block in the
[Screenshots section of the main README](../../README.md) (or link the
files from there directly).

Suggested shots and filenames:

| File | What to capture |
| --- | --- |
| `schematic-editor.png` | The schematic editor with a wired schematic open |
| `symbol-chooser.png` | The symbol chooser showing a symbol preview |
| `pcb-editor.png` | The PCB editor with a board built from a connection table |
| `footprint-browser.png` | The Footprint Browser with a footprint preview |

Landscape captures straight from the iPad are ideal — no resizing needed;
the README displays them at 49% width in pairs.
